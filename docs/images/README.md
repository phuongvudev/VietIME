# Ảnh chụp màn hình cho tài liệu

`README.md` và `docs/HUONG_DAN_SU_DUNG.md` dùng các ảnh dưới đây. Ảnh nào chưa có thì tài liệu hiện chỗ trống.

| File | Chụp gì | Cách chụp |
|---|---|---|
| `menu.png` ✅ | Menu bộ gõ (bấm biểu tượng **Vi**) | Mở menu → ⌘⇧4 → kéo chọn vùng menu. *(Ảnh hiện tại là bản cũ, nên chụp lại để có đủ mục mới.)* |
| `installer-welcome.png` ✅ | Trang chào của trình cài đặt | Mở file .pkg → ⌘⇧4 → Space → click vào cửa sổ |
| `installer-done.png` | Trang "Đã cài xong VietIME" | Như trên, ở trang cuối |
| `input-menu.png` | Danh sách bàn phím trên thanh menu, có dòng VietIME | Bấm biểu tượng bàn phím → ⌘⇧4 → kéo chọn |
| `input-sources.png` ✅ | System Settings → Keyboard → Input Sources có VietIME | ⌘⇧4 → Space → click cửa sổ |
| `input-sources-add.png` ✅ | Hộp thoại **+** → Vietnamese → VietIME | ⌘⇧4 → Space → click cửa sổ |
| `hud.png` | Ô **VI**/**EN** khi bấm Ctrl+Shift | Bấm Ctrl+Shift rồi ⌘⇧4 thật nhanh (HUD hiện 0,8 giây). Dễ hơn: ⌘⇧5 → Options → Timer 5 giây |
| `typing-demo.png` | VS Code với đoạn code có comment/chuỗi tiếng Việt và popup gợi ý | ⌘⇧4 → kéo chọn vùng editor |
| `uninstall-dialog.png` | Hộp thoại **Gỡ cài đặt VietIME…** | Mở hộp thoại → ⌘⇧4 → Space → click → bấm **Huỷ** |

Mẹo:
- Khi chụp cả cửa sổ (⌘⇧4 → Space), giữ ⌥ lúc click để bỏ bóng đổ.
- Đặt đúng tên file như bảng trên rồi chép vào thư mục này.
- Nên để chiều ngang ảnh dưới 1600px cho nhẹ repo.
