Bộ gõ tiếng Việt cho Mac, gõ code không vướng.

VietIME hỗ trợ Telex và VNI, không gạch chân khi gõ. Trong VS Code, Xcode hay JetBrains, gợi ý của editor vẫn hiện bình thường, từ khoá được giữ nguyên, còn comment và chuỗi vẫn gõ tiếng Việt được.

Tính năng

Không gạch chân

Chữ được thay trực tiếp. Popup gợi ý, Tab/Enter chọn gợi ý và tự đóng ngoặc vẫn chạy như khi gõ tiếng Anh.

Hiểu code

Giữ nguyên class, useEffect, if, max. Trong comment và chuỗi thì tự gõ tiếng Việt.

Sửa dấu tại chỗ

Đặt con trỏ vào từ đã gõ rồi gõ phím dấu: việt + s → viết. Không phải xoá cả từ.

Gõ tự do

Dấu gõ ở cuối từ đều được: vietej, nguoiwf. Chọn kiểu dấu mới (hoà) hoặc cũ (hòa).

Theo từng app

Mỗi app nhớ chế độ riêng. Bấm Ctrl+Shift để bật/tắt tiếng Việt cho app đang dùng.

Cài & gỡ dễ

Cài bằng file .pkg, không cần log out. Gỡ ngay trong menu bộ gõ.

Gõ code và tiếng Việt trong cùng một file

Ở đầu mỗi từ, VietIME đọc đoạn text trước con trỏ để biết bạn đang ở code, comment hay chuỗi. Ở code thì từ khoá được giữ nguyên. Ở comment và chuỗi thì bỏ dấu bình thường.

Nếu bộ gõ đoán sai: gõ thêm z để ép bỏ dấu (maxz → mã), hoặc gõ lặp phím dấu để giữ tiếng Anh (maxx → max).

Cài đặt trong 1 phút

  1. Tải file VietIME-<phiên bản>.pkg ở trang Releases.
  2. Bấm đúp, chọn Continue → Install rồi nhập mật khẩu máy.
  3. Bấm biểu tượng bàn phím trên thanh menu và chọn VietIME. Đổi bộ gõ nhanh bằng Ctrl+Space.

Chưa thấy VietIME? Vào System Settings → Keyboard → Input Sources → Edit… → + → Vietnamese → VietIME.

Hỏi đáp

VietIME có miễn phí không?

Có. Tải file .pkg từ trang Releases trên GitHub.

Chạy trên macOS nào?

macOS 12 Monterey trở lên, trên cả máy Apple Silicon và Intel.

Gõ code trong VS Code có bị mất gợi ý không?

Không. VietIME thay chữ trực tiếp thay vì dùng chữ gạch chân, nên gợi ý của editor và phím Tab/Enter vẫn hoạt động.

Tôi quen gõ Telex/VNI như Unikey, có dùng được không?

Được. Quy tắc Telex và VNI quen thuộc, kèm gõ tự do, tự đặt dấu đúng chỗ và tự khôi phục từ tiếng Anh.

Chọn VietIME mà không gõ được?

Vào Input Sources, xoá mọi mục VietIME, log out rồi log in lại, sau đó thêm VietIME lại.

Gỡ cài đặt thế nào?

Bấm biểu tượng Vi trên thanh menu → Gỡ cài đặt VietIME…
