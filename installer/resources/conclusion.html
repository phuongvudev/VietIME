Đã cài xong VietIME 🎉

  1. Bấm biểu tượng bàn phím trên thanh menu → chọn VietIME, hoặc bấm Ctrl+Space / 🌐.
  2. Gõ thử: tieengs Vieetj → tiếng Việt.
  3. Ctrl+Shift (nhấn rồi thả): bật/tắt tiếng Việt cho app đang dùng.
  4. Bấm vào biểu tượng Vi để đổi Telex/VNI, kiểu dấu, chế độ cho từng app.

Chọn VietIME mà không gõ được? Vào Input Sources, xoá mọi mục VietIME (nút −), log out rồi log in lại, rồi thêm VietIME lại.
Chưa thấy VietIME? Vào System Settings → Keyboard → Input Sources → Edit… → + → Vietnamese → VietIME.
Muốn gỡ: menu Vi → Gỡ cài đặt VietIME…
